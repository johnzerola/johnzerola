## Projeto em destaque

### [Horários em lote](https://github.com/johnzerola/ifood-horarios-em-lote)

Extensão experimental para organizar produtos em grupos e aplicar horários semanais de disponibilidade no Portal iFood. A fila pode ser interrompida; isso não pausa a disponibilidade do item nem restaura automaticamente o horário anterior.

**Validação documentada:** um produto, sete dias, com reabertura do calendário para conferir o resultado. A versão publicada é mais recente que a versão usada nessa validação; o README do projeto detalha o escopo e o que falta verificar.
